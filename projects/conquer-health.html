평가 기준을 응답 규칙으로 옮긴 의료 AI 개선

2026.08팀 해커톤 · 20시간

루닛의 의료 특화 모델 L2-preview를 활용해 건강 상담 응답을 개선하고 HealthBench 평가 하네스를 보완한 프로젝트입니다.

프로젝트 저장소 ↗응답 규칙 변경 커밋 ↗
기여와 역할

개발 중 비교 결과를 바탕으로 집중 방향을 제안하고, HealthBench 기준 분석과 팀의 응답 규칙·하네스 공동 개선에 참여

결과

팀은 정식 평가 3라운드 평균 46.51점으로 평가 참여 14팀 중 1위를 기록하며 의료 특화 파운데이션 모델 해커톤 벤치마크상을 받았습니다.

사용 기술
PythonHTTP APIDockerMCPLLMHealthBench
목차점수 정체 상황에서 비교 결과로 방향 제안평가 관점을 응답 행동 규칙으로 구체화실행과 실패 조건 점검관련 자료

점수 정체 상황에서 비교 결과로 방향 제안

MCP 기반 외부 검색 접근의 점수가 기대만큼 오르지 않았고, 호출을 줄인 팀 실험에서는 점수 상승을 확인했습니다.

사전 합의한 시점에 당시 최고 대시보드 점수를 기록한 구현을 중심으로 남은 보완 시간을 집중하자고 제안했습니다.

  • 모델 직접 호출과 응답 잘림·빈 응답 재시도 중심으로 최종 제출안 정리
  • 검색 접근을 배제한 비교 결과를 팀의 공통 판단 근거로 활용

평가 관점을 응답 행동 규칙으로 구체화

HealthBench 평가 기준을 분석한 뒤 팀과 함께 질문의 모든 요구를 다루기, 위험 신호 안내하기, 답을 바꿀 핵심 정보가 부족할 때 질문하기를 응답 규칙으로 정리했습니다.

정보가 부족하더라도 가능한 설명을 먼저 제공하도록 지시를 다듬었습니다.

  • 기존 생성 요청의 마지막 사용자 메시지에 ANSWER_INSTRUCTION 반영
  • 규칙 반영을 위해 별도 LLM 호출을 추가하지 않음

실행과 실패 조건 점검

OpenAI 호환 제출 서버와 질의 분류·MCP 검색 후보를 구현한 뒤 실행 결과를 확인하며 수정했습니다.

호출 동시성 제한과 요청별 시간 예산을 실험하고, 시간 초과 후 재시도에도 응답 지시문이 유지되는지 확인하는 회귀 테스트를 추가했습니다.

  • 다국어·응급 대화를 점검하는 합성 테스트 도구 구성
  • 정식 평가 점수는 팀 전체 구현의 결과이며 개별 규칙의 독립 효과를 뜻하지 않음
