공동저자 · 비매품 단행본 · ISBN 979-11-94546-10-8
WDSC 2025 / 2025

OSTEP 교재 기반 임베딩 모델의 구조적 특성과 검색 증강 생성 성능 비교 연구

운영체제 교재의 개념이 임베딩 공간에 어떻게 표현되는지 분석하고, 모델·인덱스 선택에 따른 RAG 응답 품질과 저장 비용을 비교했습니다.

연구 목적
OSTEP의 가상화·병행성·영속성 개념이 벡터 공간에서 구분되는지, 이 구조가 검색과 답변 품질에 어떻게 연결되는지 살폈습니다.
실험 방법
교재를 5문장 단위·20% 중첩 청크로 나누고 E5-Small·Base·Large를 PCA와 거리 분석으로 비교했습니다. ANNOY·FAISS(HNSW·IVF-Flat) 인덱스와 Llama-3.1-8B-Instruct를 조합해 10개 질의응답을 RAGAS로 평가했습니다.
주요 결과
실험 범위에서 HNSW + E5-Large가 Faithfulness 0.897, Context Precision 0.852로 가장 높았습니다. 모델 규모가 커질수록 개념 군집이 뚜렷했지만, Large의 평균 인덱스 크기는 17.5MB로 Small(7.2MB)의 약 2.4배였습니다. 소규모 평가에서 품질과 저장 비용의 차이를 확인했습니다.

Bo-seung Kim, Juhee Park, 외 4명

KCC 2025 / 2025

RocksDB에서 Compaction Style에 따른 성능 변화 분석

같은 RocksDB에서도 Compaction 정책에 따라 쓰기 비용과 읽기 성능이 달라지는 이유를 실험하고, 워크로드에 따른 정책 선택의 근거를 제시했습니다.

연구 목적
Leveled·Universal·FIFO 정책의 읽기·쓰기 성능과 쓰기 증폭(WAF)을 비교해, 어떤 작업에 각 정책이 유리한지 분석했습니다.
실험 방법
동일 환경에서 db_bench로 값 크기 4KB의 데이터 1,000만 건을 랜덤 쓰기한 뒤 랜덤 읽기를 수행했습니다. 처리율·지연시간·WAF와 실제 조회 성공률(Hit Rate)을 함께 비교했습니다.
주요 결과
Leveled는 Universal보다 읽기 처리율이 약 1.3배 높았지만 WAF도 1.31배 높았습니다. FIFO는 쓰기 시간과 WAF가 가장 낮은 대신 데이터 삭제로 조회 성공률이 낮아졌습니다. 단일 정책의 우열보다 워크로드별 절충이 중요하며, 혼합 워크로드 검증은 후속 과제로 남겼습니다.

박주희, 신호진, Guangxun Zhao, 최종무
